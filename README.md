# Time-Series and AI Demos

These simple demos run entirely in **Google Colab**. You do not need to install Python on your computer.

## How to open a notebook

1. Click the notebook file on GitHub.
2. Click **Open in Colab**.
3. Run the cells from top to bottom using the **▶** button.
4. Wait for each cell to finish before running the next one.

---

## 1. Student Scores Demo

Open:

`time_series_students_110_colab.ipynb`

This demo uses a CSV file containing the scores of 110 students.

### Steps

1. Run the first cell.
2. An **Upload CSV** button will appear.
3. Click the button and upload:

   `student_scores_110.csv`

4. After the file is uploaded, run the remaining cells one by one.
5. Follow the instructions shown inside the notebook.

> **Important:** Do not rename the CSV file.

## 2. ECG Demo

Open:

`ECG_PVC_Demo_Colab.ipynb`

This demo compares a normal heartbeat with an abnormal heartbeat using ECG time-series patterns.

### Steps

1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Observe the ECG graphs and the AI prediction.

No file upload is required.

---

## 3. Drone Demo

Open:

`Drone_TimeSeries_Trigonometry_Colab.ipynb`

This demo shows how a drone uses distance, direction, angle, trigonometry, and time-series data.

### Steps

1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Use the interactive controls to move the drone or obstacle.
4. Observe how the distance, angle, and movement direction change.

No file upload is required.

---

## If an error occurs

Select:

**Runtime → Restart session**

Then run all cells again from the beginning.
